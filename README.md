# SNS全自動投稿

毎週日曜の夜に、来週1週間分（7本）の投稿をAIが作り、毎日お昼12時ごろにInstagramへ自動で投稿します。

- `photos/` に入れたお店の写真をAIが実際に見て、その写真に合った見出し・キャプション・ハッシュタグを書きます
- 写真に見出しの帯を重ねた投稿用画像（1080×1350）を自動で作ります
- 写真は使った回数が少ない順に選ぶので、同じ写真ばかりになりません
- Instagramのトークン（60日で切れる）は月2回自動で延長します
- 動くのはGitHub Actionsなので、サーバー代はかかりません

## ふだんの運用

- 何もしなくても毎日投稿されます
- 来週だけのお知らせがあるときは `config.yaml` の `news:` に書く（日曜20時までに）
- 予定の投稿を直したいときは `queue/日付.json` の文章を書き換える
- 投稿をやめたい日は `queue/日付.json` を削除する
- 全部止めたいときは「Actions」タブで各ワークフローを「Disable workflow」にする
