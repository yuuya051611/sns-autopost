# SNS全自動投稿（RARE STELLA）

毎週日曜の夜に、来週1週間分（リール動画4本＋画像3本）をAIが作り、「確認待ち」にします。
承認（Merge）したものだけが、毎日お昼12時ごろにInstagramへ自動投稿されます。

- 写真の用意は不要。会社資料と同じ色のデザインで、文字が動くリール動画と画像を自動で作ります
- 投稿内容は `config.yaml` の情報をもとに作ります。根拠のない数字や保証は書かない設定です
- Instagramのトークン（60日で切れる）は月2回自動で延長します
- 動くのはGitHub Actionsなので、サーバー代はかかりません（AIの文章生成代のみ）

## 毎週やること

1. 日曜の夜にGitHubから「【確認お願いします】来週の投稿7本」というお知らせが届く
2. 開いて、画像・動画・文章を確認する
3. 問題なければいちばん下の「Merge pull request」→「Confirm merge」を押す
4. 直したいところがあれば、Claudeに「◯曜日の投稿をこう直して」と伝える

## その他

- 来週だけのお知らせがあるときは `config.yaml` の `news:` に書く（日曜20時までに）
- 投稿をやめたい日は、確認画面でその日のファイルを消してからMergeする（Claudeに頼んでもOK）
- 全部止めたいときは「Actions」タブで各ワークフローを「Disable workflow」にする
